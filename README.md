# 🚀 Android Journey

A personal learning repository for Android development with **Kotlin** and **Jetpack Compose**.

This repository contains small apps, practice tasks, experiments, and notes created while learning modern Android development.

The main goal of this repository is not to store finished commercial projects, but to track my progress, practice new concepts, and keep everything I learn in one place.
